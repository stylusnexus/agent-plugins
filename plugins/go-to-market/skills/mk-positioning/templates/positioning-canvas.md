## One-line positioning statement
This fill-in-the-blank format is Geoffrey Moore's, from *Crossing the Chasm* (Source: MistyWest, "Building a Positioning Statement," citing Moore's template verbatim — https://www.mistywest.com/wp-content/uploads/2021/03/MistyWest-Building-a-Positioning-Statement.pdf); April Dunford, whose five-component method the rest of this canvas follows, argues the opposite — she's written that this kind of fill-in-the-blank exercise is "not only pointless but potentially dangerous" because it "assumes that there is only one answer for each of the blanks" when "most products could easily be positioned in multiple different market categories" (Source: April Dunford, "An Introduction to Positioning" — https://www.aprildunford.com/post/an-introduction-to-positioning). Use the one-liner as a compressed summary of the five components above, not as a substitute for working through them — and skip it if it starts driving the answer instead of restating it.

For [segment], who [need / current alternative], [product] is the [category] that [differentiated value] — unlike [alternative].
>

## Stakeholder check (run before shipping)
Per [stakeholder-check.md](../references/stakeholder-check.md): a positioning claim that only checks out on one axis is incomplete.

## Example (fictional)
*A fictional illustration only — no real product, company, or numbers.*

| Field | Entry |
|---|---|
| Alternative | A shared spreadsheet the team already uses to track the same thing by hand |
| Differentiated capabilities | Syncs across the team in real time; flags conflicting entries before they're saved |
| Value | Nobody redoes work because they were looking at a stale copy |
| Segment | Small teams of 3–8 already sharing a spreadsheet for this, hitting version conflicts weekly |
| Category | "A shared tracker that can't go stale" |
| One-liner | For small teams tracking their work by spreadsheet, ExampleTracker is the shared tracker that can't go stale — unlike a spreadsheet, nobody's ever looking at yesterday's copy. |
