# Outreach tracker

A running log of every 1:1 outreach message sent — cold, warm-introduced, or a setup-service offer. One row per send, including each follow-up (a recipient contacted three times gets three rows) — that's what keeps the reply-rate denominator honest: sends, not recipients or "attempts." Honor every opt-out. See `marketing-lead/references/principles.md` on measuring honestly and on plans not being permission — nothing here gets sent without the owner's sign-off first.

| Date sent | Recipient (name, company) | Path (cold / warm / setup-offer) | Channel | One verified fact used | Approved to send? | Response | Follow-up sent? | Opted out / said no? |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |
