## Example (fictional)
*A fictional illustration only — no real product, company, or numbers.*

| Field | Entry |
|---|---|
| Firmographics | 5–20 person software teams, US/EU |
| Technographics | Already using a generic project tracker; nothing dedicated to this specific task |
| Behavioral evidence | Tried a shared spreadsheet, hit version conflicts within a few weeks |
| Job — functional | Keep one shared source of truth without a meeting |
| Job — social | Look organized to the rest of the team without adding process |
| Job — emotional | Stop worrying someone's working off a stale copy |
| Trigger | Just lost work to a version conflict |
| Disqualifier | Team of one, or already paying for a full PM suite that covers this |
| Segment | Small software teams already sharing a spreadsheet for this who've hit a conflict in the last month |
