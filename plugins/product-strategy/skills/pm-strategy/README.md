# pm-strategy

This skill should be used when the user asks for product strategy, where to play, how to win, trade-offs, cost leadership, cost focus, differentiation, or differentiation focus.

[![Claude: Code full, app full](https://img.shields.io/badge/Claude-Code%20%E2%9C%94%20%C2%B7%20app%20%E2%9C%94-brightgreen)](../../../../README.md#compatibility) [![Codex / ChatGPT: Codex full, ChatGPT full](https://img.shields.io/badge/Codex%20%2F%20ChatGPT-Codex%20%E2%9C%94%20%C2%B7%20ChatGPT%20%E2%9C%94-brightgreen)](../../../../README.md#compatibility) [![Other agents: full](https://img.shields.io/badge/Other%20agents-%E2%9C%94-brightgreen)](../../../../README.md#compatibility)

Part of the [product-strategy](../../README.md) pack.

## When and how to use it

**Use it when:** You must choose which users to serve and how to win with them.

**Try:** `Should my tracker target hobby collectors or small plant shops?`

**Skip it when:** You only need a mission statement or a pricing table.

## What it looks like

Example output, invented data (fictional product).

```text
Recommendation  Differentiation focus: a narrow segment with distinct needs
Five connected choices
  Winning aspiration  first tracker collectors recommend to each other
  Where to play       collectors with 20+ indoor plants; English-speaking; app stores
  How to win          room-by-room schedules that survive travel and season changes
  Capabilities        schedule engine, species care data, reliable reminders
  Management systems  weekly review of missed-watering reports; one owner
Trade-off      Chosen: depth for collectors. Rejected: a simple app for everyone
               Sacrificed: casual owners with 3 plants (deliberate exclusion)
Riskiest assumption  collectors will pay for schedules (hypothesis, untested)
Change trigger       fewer than 1 in 10 trial users set up a second room
```

## Install

<details>
<summary>Claude Code (CLI)</summary>

Add the marketplace once, then install the pack:

```bash
claude plugin marketplace add stylusnexus/agent-plugins
claude plugin install product-strategy@stylus-nexus
```

Inside a session, `/plugin marketplace add stylusnexus/agent-plugins` and `/plugin install product-strategy@stylus-nexus` do the same. This installs the whole product-strategy pack, so pm-canvas, pm-capabilities, pm-discovery, pm-growth, pm-market-analysis, pm-objectives, pm-roadmap, pm-strategy-fit, pm-teams, pm-value-proposition, pm-vision, pm-visuals, pricing-review and product-manager come with it.

Call it as `/product-strategy:pm-strategy`, or let it start on its own when your request matches.

</details>

<details>
<summary>Claude Code desktop app</summary>

The desktop app's local sessions read the same plugin settings as the CLI, so a pack you installed from the terminal at user scope is already there.

To install from the app, add the marketplace once from a terminal with `claude plugin marketplace add stylusnexus/agent-plugins`. Then, in a local or SSH session on the **Code** tab, click **+** next to the prompt box, choose **Plugins**, then **Add plugin**, and pick **product-strategy**. Plugins do not load in the app's cloud sessions.

</details>

<details>
<summary>Codex</summary>

```bash
codex plugin marketplace add stylusnexus/agent-plugins

<summary>Other agents, Skills CLI</summary>

Skills arrive without a pack prefix: `/pm-strategy` in most agents and `@pm-strategy` in Windsurf. opencode shows `/pm-strategy` only when the skill sets an opencode-specific metadata field, and Gemini CLI starts a skill itself after you approve it.

**Note:** Optional cross-references to other pack skills need the whole pack.

</details>

<details>
<summary>Other agents, by folder</summary>

`.agents/skills` is read by Codex, Gemini CLI, Antigravity CLI, Cursor, GitHub Copilot, opencode and Windsurf. Claude Code reads `.claude/skills`. Cline does not read `.agents/skills`; use `.cline/skills` or `.claude/skills` there.

mkdir -p .agents/skills

```

**Note:** Optional cross-references to other pack skills need the whole pack.

</details>
