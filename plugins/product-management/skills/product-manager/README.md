# Using the product management suite

Start with this skill for product decisions, a guided workshop or practical teaching. It routes to thirteen sibling skills as needed. Keep the complete suite installed together so relative links resolve.

Read `SKILL.md` for the workflow and [shared principles](references/principles.md) for evidence, authorization and proportionality. Read [source notes](references/sources.md) for public framework attribution. HTML and human markup fallbacks are included in `support/`; no custom agent, connector or external skill is required for the core conversation.

Use available host tools for requested external formats and live research. Check their availability in the current session. This package does not prove that native host loading, connector access, browser rendering or any business outcome has been validated.
